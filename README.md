# Суши-бар «Кабуки» — коммерческий сайт

Статический сайт: HTML + CSS + vanilla JS, без сборки и зависимостей.
Меню, акции, цены и реквизиты — в `js/data.js`.

## Запуск

- Откройте `index.html` двойным щелчком — всё работает с диска.
- Или поднимите локальный сервер: `python -m http.server 8000`, затем `http://127.0.0.1:8000`.

Проверка расчётов: откройте `tests/pricing.test.html` в браузере — все строки должны быть зелёными.

## Структура

```
index.html              витрина, акции, меню, корзина, оформление, футер, cookie-баннер
legal.html              политика ПД, согласие на обработку ПД, политика cookie, публичный договор,
                        информация для потребителя и порядок обращений, образец кассового чека, реквизиты
css/style.css           минималистичный светлый дизайн, сетки, адаптив, диалоги, cookie-баннер
js/data.js              категории, блюда, акции, доставка, реквизиты
js/pricing.js           чистый расчёт: скидки, промокод, доставка
js/company.js           подстановка реквизитов в [data-company]
js/consent.js           cookie-согласие и точка подключения аналитики
js/app.js               каталог, фильтры, корзина, оформление, формы
js/effects.js           лёгкие эффекты: линия шапки при прокрутке, плавное появление блоков (необязателен)
tests/pricing.test.html самопроверка расчётов
REPORT.md               отчёт о проверке сайта: что исправлено и что ещё открыто
COMPLIANCE.md           таблица: требование законодательства РБ → где это на сайте → что заполнить
```

## Что заполнить перед публикацией

Все фрагменты `[ЗАПОЛНИТЬ: …]` на сайте и в `js/data.js`:

- `company` в `js/data.js`: наименование/ФИО ИП, УНП, адрес, регистрация, режим работы, телефон, e-mail, адрес самовывоза;
- `company.hosting` — хостинг-провайдер в Республике Беларусь;
- `company.belgiez` — номер и дата регистрации в реестре РУП «БелГИЭ»;
- `company.tradeRegister` — дата включения в Торговый реестр и регистрационный номер (обязательно на главной странице);
- `company.complaintsPerson` — лицо, уполномоченное рассматривать обращения покупателей;
- `company.executiveCommittee` — телефоны исполкома по месту регистрации, принимающего обращения;
- `company.complaintBook` — место нахождения книги замечаний и предложений;
- зона доставки, сроки и условия в `js/data.js` (`delivery`) и в текстах. Числа `fee`, `freeFrom`, `minOrder` из `delivery` применяются к расчёту автоматически, но цифры в текстах страниц и в `legal.html` нужно менять вручную;
- даты редакций, e-mail для обращений и банковские реквизиты в `legal.html`;
- платёжный сервис онлайн-оплаты (сейчас в оформлении доступна оплата при получении);
- актуальные даты и условия акций в `js/data.js` (`promos`).

Юридические тексты — базовые шаблоны. Перед запуском их должен проверить юрист.

## Меню и цены

Правится в `js/data.js`:

```js
{
  id: 'roll-philadelphia',
  cat: 'rolls',                 // sets | rolls | sushi | hot | drinks | sauces
  name: 'Филадельфия классик',
  desc: 'Лосось, сливочный сыр, огурец, рис, нори.',
  weight: '8 шт · 280 г',
  price: 18.5,
  oldPrice: 21,                 // необязательно: старая цена и бейдж скидки
  img: 'photo-1579584425555-c3ce17fd4351',  // ID фото Unsplash
  tags: ['hit']                 // hit | spicy | veg
}
```

Фото задаются ID с `images.unsplash.com`. Чтобы использовать свои файлы, положите их в `assets/` и укажите путь в `img`, например `img: 'assets/philadelphia.jpg'` (значение с точкой или `/` берётся как путь без изменений).

## Заказы

`js/app.js`, константы `ORDER_ENDPOINT`, `SUBSCRIBE_ENDPOINT`, `FEEDBACK_ENDPOINT` (заказ, подписка, обратная связь).

- Пустая строка — демо-режим: данные никуда не отправляются, и сайт прямо говорит об этом пользователю («Демо-режим: заказ не отправлен»). Перед публикацией обязательно укажите адреса всех трёх обработчиков.
- Укажите URL обработчика — заказ уйдёт `POST` с JSON `{ name, phone, email, method, address, time, payment, comment, consent, promo, items, totals }`. Ожидаемый ответ: `{ "orderNumber": "..." }` (необязательно).
- `consent` — `{ given, at, document }`: когда и на основании какого документа получено согласие на обработку персональных данных. Храните его на стороне сервера вместе с данными. Подписка отправляет `{ email, consent }`, обратная связь — `{ name, contact, message, consent }`.

## Аналитика и маркетинг

Подключаются только после согласия пользователя:

- `js/consent.js` → `loadAnalytics()` — вставьте код счётчика;
- `loadMarketing()` — рекламные пиксели;
- или `SushiConsent.registerAnalytics(function () { ... })`.

До согласия никакие сторонние скрипты не загружаются. Настройки cookie открываются кнопкой в футере и по ссылке `index.html?cookie=1`.

## Согласия

Чекбоксы в формах заказа, подписки и обратной связи не отмечены по умолчанию. Без отметки отправка блокируется с сообщением. Ссылки ведут на `legal.html#consent` (текст согласия) и `legal.html#privacy` (политика).

## Доступность

Клавиатурная навигация, `aria`-атрибуты, `aria-live` для ошибок и счётчиков, нативные `<dialog>`, `prefers-reduced-motion`, адаптив от 360 px.
